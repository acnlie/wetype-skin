The original transparent VP9 animations were converted to transparent PNG
sprite sheets at 128x128 and 24 frames per second for offline native Windows
rendering. Original filenames, URLs and source/output hashes are in clips.json.
Confirmation, cancellation and mode feedback use selected portions of the source
animations. The source start time is recorded for every sprite sheet.

This release contains 19 source-derived action sheets and seven sign variants
(26 sheets total). The sign variants use the empty-sign segment of the source
animation, with Chinese, English, half-width, full-width and punctuation labels added by
WeType Skin Studio. Their source hashes and derivation are recorded in clips.json.

Character identity reference: https://github.com/Neko3000/deepseek-whalechan
No image or code from that reference project is redistributed in this package.
