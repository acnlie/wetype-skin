# WeType Skin Studio 0.3.0 预发布

本次提供 Windows x64 EXE 和 macOS Intel DMG。Mac 功能尚未与 Windows 完整对齐，适合作为预发布体验版。

## 本次更新

- Windows 和 Mac 顶栏增加 GitHub 仓库与 X 主页图标，用默认浏览器打开。
- Mac 桌宠改为跟随微信输入法浮窗；浮窗不可见时隐藏，后台进程继续运行。
- Mac 接入候选出现、停留、部分输入按键和系统输入源切换动画；大小与动画开关可保存。
- DMG 提供 Applications 拖放入口；Windows EXE 内嵌独立桌宠和前端资源。
- 修复 Windows 编辑器中桌宠动作预览素材加载后画布仍为空白的问题；安装包已包含修复。

## 安装

Windows：运行 `WeTypeSkinStudio-Windows-x64.exe` 安装到当前用户目录。安装包携带微软签名的 WebView2 离线完整安装器；系统缺少运行时时自动安装，无需联网或手动下载。支持的 Windows 10 2004+ 自带 .NET Framework 4.8。原生换肤仅支持已核对的微信输入法 2.1.4.6。

Mac：打开 `WeTypeSkinStudio-macOS-Intel.dmg`，将应用拖到 Applications 后打开。需要 macOS 13+，本包仅适用于 Intel；桌宠和副本准备程序均随包提供，不要求 Python 或开发工具。按键动画可能需要在“系统设置 → 隐私与安全性 → 辅助功能”重新授权实际安装位置。

## 已知限制

- Mac 已在 Intel 微信输入法 2.2.3（657）上确认副本正常出词、真实候选栏背景变为暮紫。图片、透明度与工具条样式尚未完成整体验收；初次输入源发现仍可能延迟。
- Mac 窗口跟随采用浮窗尺寸分类；工具条、多屏、微信内部中英模式、半角／全角和标点反馈尚未完整验收。
- Mac 使用本地 ad-hoc 签名，未做 Developer ID 公证。此包不等于已公证的公开稳定版；不要通过关闭 SIP 或全局 Gatekeeper 运行。
- Windows EXE 未做商业代码签名。本轮验证为构建和共享前端语法检查，没有重新执行完整输入法回归。

## 恢复

Windows 使用“还原官方”恢复原生皮肤；关闭工作室不会自动还原。Mac 使用“还原官方”先切回并确认官方微信输入源，再停止副本，官方输入法包未改动。Mac 菜单栏“鲸 → 退出桌宠”仅停止桌宠，重新打开工作室可启动它。
